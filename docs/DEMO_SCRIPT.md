# Demo video script — 3:00 max

One take, screen capture at 1280+ width, RB2302 course loaded (it already
is). Talk over it; the app does the visuals. Numbers said aloud must match
the screen — judges check.

**0:00–0:20 · The problem, over the Home screen.**
"Students re-read notes because it feels productive — the evidence says
retrieval is what works, but the tools that do retrieval don't talk to your
actual course material. This is Flashbang: my lecture PDFs, tutorial sheets
and flashcards in one loop, on my own API key. That tile says em-dash, not
0% — this app never claims a retrieval that didn't happen."

**0:20–0:50 · Ingest → course page (RB2302).**
Open RB2302. Point at the fixed metrics band, then the Notes rail section.
"A 242-page deck became 41 topics for seventeen cents — page ranges, time
estimates, all editable. The nav strip repeated on every slide was 37% of
the text; it's stripped before any model sees it."

**0:50–1:20 · Primer + reader.**
Open a topic → the primer card. "Before reading anything new: the gist, one
everyday analogy — with a mapping AND where the analogy breaks, because an
unbounded analogy installs misconceptions — for a thirtieth of a cent,
cached forever." Scroll a page; drag a blackout across a sentence — it snaps
per line to the words. "Boxes snap to the text under the drag; on diagrams
they stay where you drew them."

**1:20–1:50 · Review.**
Start today's review. Type an answer (have one ready). Grade card appears:
"One fast model call: what I had, the gap, a memory hook — and the schedule
consequence as one track: four days instead of twelve. Only a perfect answer
animates." End session → the report replaces the transcript: "Recall in
marks, every gap with its expected answer and a re-read button."

**1:50–2:20 · Tutorials.**
Tutorials section. Click a topic chip ("Backpropagation · 5"). "Six problem
sheets became 79 questions, each part separate, tagged against MY notes —
weak topic, click, its questions, already open. Answer opens the solution's
actual page — worked solutions are retrieved, never rewritten." Click
Answer ›.

**2:20–2:45 · The NotebookLM round-trip + Analytics.**
Show the copy-prompt card, then paste a prepared reply, Apply — bars move,
"ext" marker. "Study anywhere; graded evidence comes home, decaying like a
first recall — it never touches the exam projection." Flip to Analytics →
SPEND tab. "Every claim in this video is on this screen: about a dollar
total to load four courses. The app bills itself honestly." (Say whatever
the tab shows that day — it was $1.06 on 18 Aug.)

**2:45–3:00 · Close.**
"Feature-complete, twelve test suites, under a dollar a week for five
modules. The next step is a semester of real use — the only evaluation that
counts. Repo and write-up linked below."
