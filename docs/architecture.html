Router — 3 layers, cheapest first

Orchestrator — stateful routing

DATA & MATH
SQLite — single source of truth
courses → pdfs → pages → topics → notes/cards (triple FK, derived server-side) · study log auto-written by session tools · answer log (quality + confidence) · plan · FKs enforced, cascades designed
database.py · flashbang.db
Decay engine — pure functions, no LLM
R = e−t/S, S ≈ 3.476 × SM-2 interval (due date ⇒ 75% retention) · never-reviewed = 0 · completion % = minutes-weighted topic mastery · computed at read time, nothing stored
mastery.py · sm2.py · planning.py · stats.py
Semantic search
Concept embeddings, cosine ranking, relevance threshold; answers must cite course/PDF/topic or admit absence
search.py · embeddings.py
Guardrail philosophy — the LLM proposes, deterministic code disposes: page ranges normalized mechanically · ids type-checked at the tool boundary · session counts derived from DB timestamps · every persist gated by human approval · agents forbidden from claiming success without a tool result.   Verified — 5 offline test suites + dated live-eval log (TESTING.md): 6 real documents ingested (242-page deck: 14 topics, 8.4 h, $0.15), 5 production bugs caught by live testing and fixed.
